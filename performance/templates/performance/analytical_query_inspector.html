Inspector context

Deterministic means the same supported inputs and query contract produce the same computation. It does not verify that the underlying journal data is accurate or complete.

Profit uses the journal's recorded Profit column only. Commission and Swap are not added.

Date-based queries group by the calendar date as recorded in the journal. No timezone conversion is applied.

No LLM, external AI provider, RAG retrieval, or external network request is used by this analytical workflow.
