Claim boundary

Deterministic means reproducible computation and deterministic checks. It does not establish that source journal data or model output is factually correct. Provider output remains subject to human review.

Passing deterministic checks does not mean the output is factually verified or correct.

Deterministic / no external provider

These surfaces use fixed local workflows. They do not invoke an LLM, external provider, or RAG retrieval over the network.

Deterministic Analytical Query Inspector

Fixed analytical query catalogue. Deterministic computation over the current authenticated journal. Profit is the recorded Profit column only; Commission and Swap are excluded. Date grouping uses the recorded calendar date; no timezone conversion is applied. No LLM, provider, RAG retrieval, or external network call.

Open Deterministic Analytical Query Inspector

Retrieval Inspector

Deterministic TF-IDF retrieval and evidence/provenance inspection for the authenticated journal-scoped workflow. No external provider invocation. This is not vector search.

Open Retrieval Inspector

Grounding Inspector

Deterministic evidence-grounding contract. A candidate response is supplied manually and checked by deterministic validation. This manual workflow does not make an LLM or provider call. Passing deterministic checks does not mean the candidate is factually verified or correct.

Open Grounding Inspector

Offline evaluation

Sprint 7 added an offline adversarial evaluation corpus and evaluation harness. It covers expected-pass, expected-reject, and documented known-limitation behaviour, plus mutation and kill-matrix evidence. There is no interactive route for that harness on this page.

Controlled external provider

This section is separate from the deterministic surfaces above. It describes a controlled, staff-gated inspector. Opening this Evidence page does not send a provider request.

Provider Grounding Inspector

Staff-only controlled inspector for the existing provider-backed grounding workflow. Two controlled synthetic live canaries were executed in the closed Sprint 8-9 work. Both provider responses were rejected by the deterministic validator with SCHEMA_INVALID_JSON. That demonstrates the trust boundary rejecting invalid output. It does not demonstrate model-output quality or accepted output.
